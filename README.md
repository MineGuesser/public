## Before you post

- **Search first.** If someone already reported it, add a 👍 to their issue instead of opening a new one. Votes are how we decide what gets fixed and built first.
- **One issue per report.** Two bugs means two issues, so each one can be tracked and closed on its own.
- **Exploits and security problems go private.** Use [**Report a security issue**](https://github.com/MineGuesser/public/security/advisories/new) instead of a public issue. Only the team can see those reports.

## What happens after you post

| Label | Meaning |
|---|---|
| `triaged` | We've read it and sorted it. |
| `priority: P0` … `P3` | How urgent it is. P0 means the server is broken, P3 means nice-to-have. |
| `needs-info` | We need a bit more from you to act on it. Check the comments! |
| `approved` | It's on the list to be worked on. |
| `duplicate` | Already reported elsewhere. The comment links to the original. |

When a fix or feature ships, the issue will be closed.
